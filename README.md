このリポジトリでは、BOOTHで配布するPHP版リンク検査スクリプトの説明書と設定例を公開しています。購入前に、必要な環境・機能・制限・導入作業を確認できます。

**スクリプト本体はBOOTHで配布します。このリポジトリには含まれていません。** 以下のマニュアルに記載したコマンドは、購入した配布ファイルをサーバーへ配置してから実行してください。

設定項目は[設定例](conf/linkcheck_php_example.json)で確認できます。

WordPressの公開ページから内部・外部リンクを抽出し、HTTP応答を検査するスクリプトです。サーバーのcronから夜間に全件検査を起動し、通知対象がある場合に結果をメールで受け取ります。全件検査の間、手元のPCやSSH接続を開いて待つ必要はありません。

## 必要な環境

- `/bin/sh`、SSH、cronを利用できるサーバー
- PHP CLI 8.4以上
- PHP拡張：curl、dom、libxml、XMLReader、intl、mbstring、zlib、pcntl、openssl
- PHP/cURLが利用できるCA証明書と、実行可能なsendmail互換コマンド
- 検査対象の公開サイト、通知先と利用可能な送信元メールアドレス

Composer・追加のPHPパッケージ・Pythonは運用に不要です。Web用のPHPとCLI用のPHPは異なる場合があります。必要な関数を含む環境の確認方法は、導入マニュアルで案内します。

## 導入の流れ

[導入マニュアル](docs/INSTALLATION_GUIDE.md)を最初から順に進めてください。

1. 公開領域外へ配置し、本番用設定を作る。
2. `--check` で設定と実行環境を確認する。
3. 本番と別の設定ファイル・`site_id` で、掲載元1ページの手動テストとメール受信を確認する。
4. 本番用設定と `--auto-initial` を指定して、夜間のcronを登録する。
5. 全件検査と初回メールの配送受付が成功すると、次回から通常通知へ自動で切り替わる。初回結果と実際の受信を確認する。

手動テストの詳細は[手動テスト手順](docs/MANUAL_TEST_PROCEDURE.md)、導入後の設定・判定・通知・ログ・停止方法は[操作説明](docs/PHP_OPERATIONS.md)を参照してください。

cronの登録コマンドと切替条件は導入マニュアルに掲載しています。設定画面の操作を説明するPHP版ブログ記事は参照先が未確定のため、現時点ではリンクを掲載していません。

## 結果と通知

既定の結果保存先は `reports/linkcheck_php/<site_id>/<実行ID>/` です。`summary.md` に完了状態・判定件数・メール受付結果、`links.tsv` に全掲載箇所、`sources.tsv` に掲載元の取得状態、`requests.jsonl` にHTTP要求記録を保存します。

`--auto-initial` は、その設定での初回成功記録がなければ、リンク切れがなくても初回結果メールを送ります。未完了・配送失敗なら次回も初回として実行し、成功後はcronを書き換えず通常通知へ移ります。実際のメール受信は自動判定できないため、受信箱を確認してください。通常実行は主に再確認済みの404/410を通知し、同じリンク切れが残れば次回も通知します。判定保留・接続エラー・未完了だけではメールを送らないため、保存結果も確認してください。詳しい条件は[通知条件](docs/PHP_OPERATIONS.md#通常実行と通知条件)を参照してください。

Amazon関連の直接リンク・短縮リンクは、クリック集計への影響を避けるため通信前に除外します。除外やメール未着は、リンク先の正常確認を意味しません。

## 検査の範囲と制限

全件検査とは、設定した収集方式・許可範囲・上限に基づく検査です。サイト全ページの網羅や、リンク先内容の正常性を保証するものではありません。記事編集・リンク削除・ログイン・JavaScript実行・ページ内アンカーの存在確認は行いません。

要求は逐次実行し、要求間隔と再確認待機を守ります。毎回最初から検査し、途中再開や実行をまたぐ成功キャッシュはありません。時間・件数上限で未完了になる場合は、そのまま全件監視として運用を開始しないでください。

設定・レポート・ログは公開領域外で管理してください。URLのクエリやメールアドレスが残ります。終了から30日を過ぎたログ・レポートは、同じサイトの次回検査開始時に自動削除します。実行中・終了不明の記録と `state/` は残します。必要な結果は事前に別の場所へ保存してください。対象と例外は[操作説明](docs/PHP_OPERATIONS.md#保存期間と自動削除)を参照してください。
